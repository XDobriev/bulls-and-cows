# Bulls and Cows (Быки и Коровы)

Классическая логическая игра «Быки и коровы» (Bulls and Cows) с поддержкой различных систем счисления (двоичная, восьмеричная, десятичная, шестнадцатеричная) и настраиваемой длиной секретного числа (от 2 до 6 цифр).

Вся игровая логика написана в строгом функциональном стиле: чистые функции без классов и побочных эффектов, неизменяемые структуры данных, функции высшего порядка, каррирование, мемоизация и рекурсия.

## Стек технологий

- **Язык**: TypeScript
- **Тестирование**: Vitest (по принципам TDD и FIRST)
- **Сборщик / Dev-сервер**: Vite
- **Линтинг и форматирование**: ESLint + Prettier
- **Git-хуки**: Husky + lint-staged (pre-commit: lint-staged, pre-push: test)

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка проекта для продакшена
npm run build

# Предпросмотр собранной версии
npm run preview

# Запуск тестов
npm test

# Проверка стилей и линтинг
npm run lint
npm run format:check
```

## Правила игры

Компьютер загадывает секретное число из уникальных цифр заданной длины в выбранной системе счисления.
Игрок вводит варианты попыток и после каждой попытки получает подсказку:

- **Быки (Bulls)**: количество угаданных цифр, стоящих на своём месте.
- **Коровы (Cows)**: количество угаданных цифр, стоящих не на своём месте.

Игра продолжается до тех пор, пока число быков не сравняется с длиной секретного числа. По завершении раунда результат (число попыток и затраченное время) заносится в таблицу рекордов в `localStorage`.
